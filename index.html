Sendora

A private, single-user Gmail automation agent.

Sendora is a personal automation tool. It connects to one Gmail mailbox — the owner's own — through the Gmail API to sort incoming mail, apply labels, and prepare draft replies for review. It never sends email on its own: every draft is left in the mailbox for the owner to read, edit, and send manually.

Who runs it

Sendora is operated by a single person, for their own mailbox only. It is not offered as a service, it has no other users, and it does not process anyone else's data.

What it does with Gmail data

  • Reads message metadata and bodies from the owner's inbox in order to classify each message.
  • Applies Gmail labels (read, categorize) to those messages.
  • Creates draft replies in the owner's mailbox. Drafts are never sent automatically.
  • Deletes nothing without explicit confirmation, and reads no other mailbox than the owner's.

Data storage

The OAuth refresh token is stored locally on the owner's Mac. Message contents are processed in memory and are not copied to any third-party service. See the privacy policy for details.
